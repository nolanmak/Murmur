## Outcome
Provide a reproducible Linux install with bring-your-own Deepgram credentials and clear prerequisites.

## Acceptance criteria
- [ ] Document supported distro/architecture and native dependency versions; build/install/uninstall from a clean target without developer-specific paths.
- [ ] Use documented XDG configuration precedence plus explicit env-file support; test process environment overrides and missing/invalid key handling.
- [ ] Protect stored credentials with restrictive permissions and never embed them in packages, diagnostics or command-line examples.
- [ ] Provide application launcher metadata and optional per-user startup; uninstall preserves user configuration unless explicitly requested.
- [ ] Document headless limitations and microphone locality: a server or remote desktop session needs its own available audio source.
- [ ] Do not advertise unsupported package formats or architectures; published artifacts include checksums and license notices.

## TDD plan
RED: isolated temporary-home tests for config precedence, malformed files, permissions and packaging manifest contents. GREEN: minimal package/install path. Validate clean install, launch, upgrade and uninstall in the declared Linux environment using synthetic configuration.

## Workflow and definition of done
- [ ] Create an isolated issue branch/worktree from updated main; keep one bounded change per PR.
- [ ] Record the failing behavioral test command/output before implementation, then the passing result; refactor without weakening assertions.
- [ ] Run `cargo fmt --all -- --check`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo test --locked --workspace`, and `python3 scripts/check-repo.py`.
- [ ] Link tests and native evidence to each acceptance criterion; explicitly leave untested criteria open.
- [ ] Use synthetic data only; no credentials, personal paths, hostnames, user audio or transcripts in Git/issues/evidence.
- [ ] Push the issue branch, open a linked PR and remove its temporary worktree after preserving committed work.
