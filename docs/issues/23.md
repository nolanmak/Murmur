## Outcome
Make Linux readiness depend on measured native behavior rather than compile-only CI.

## Acceptance criteria
- [ ] CI runs fmt, Clippy, workspace tests and repository checks on Linux and macOS; Linux integration jobs exercise an isolated session with synthetic audio and a fake provider.
- [ ] Add automated red/green coverage for manual and shortcut capture through finalization and actual target insertion; no real microphone or cloud keys in CI.
- [ ] Keep native release evidence for declared X11 and Wayland support: browser search/contenteditable, editor, terminal, cancellation, focus switch, permission denial and audio loss.
- [ ] Record exact tested versions and results using synthetic text; Wayland evidence includes native apps as well as XWayland.
- [ ] Real microphone/Deepgram checks are explicit opt-in manual gates; lack of hardware or session leaves that gate incomplete.
- [ ] Any pre-existing failing test has a reproduced baseline and linked tracking issue; do not silently exclude or weaken it to obtain green CI.

## TDD plan
RED: reproduce currently unsupported Linux flows as failing integration scenarios. GREEN: land adapters in dependency order. Refactor with full regressions and attach sanitized command results plus native evidence before announcing Linux support.

## Workflow and definition of done
- [ ] Create an isolated issue branch/worktree from updated main; keep one bounded change per PR.
- [ ] Record the failing behavioral test command/output before implementation, then the passing result; refactor without weakening assertions.
- [ ] Run `cargo fmt --all -- --check`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo test --locked --workspace`, and `python3 scripts/check-repo.py`.
- [ ] Link tests and native evidence to each acceptance criterion; explicitly leave untested criteria open.
- [ ] Use synthetic data only; no credentials, personal paths, hostnames, user audio or transcripts in Git/issues/evidence.
- [ ] Push the issue branch, open a linked PR and remove its temporary worktree after preserving committed work.
