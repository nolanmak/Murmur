## Acceptance criteria
- [ ] On macOS, holding Space for 350 ms starts exactly one session and release requests finalization; repeat events do not duplicate work. Quick taps type one space and typing rollover preserves character order.
- [ ] Space combined with another modifier does not start dictation; Fn remains available to Wispr Flow. Esc cancels capture and pending insertion, including during finalization.
- [ ] Busy sessions reject overlapping starts; stale results from a cancelled session cannot insert; maximum duration stops capture.

## Test-first implementation
