## Outcome
Microphone-only audio pipeline using FlyOnTheWall capture and resampling.

## Milestone
M1

## Dependencies
#1, #2

## Acceptance criteria
- [ ] Capture opens only the default microphone, never a system-audio tap; recording begins only on explicit Control press.
- [ ] Actual device format drives the reused anti-aliasing resampler; 44.1/48/16 kHz inputs produce mono 16 kHz PCM.
- [ ] The real-time callback does no network or blocking work; bounded overflow or device failure cancels rather than silently dropping speech.
- [ ] Release, Escape, duration limit and shutdown close the audio device and retain no recording on disk.

## Test-first implementation
First add sine-wave/fixture resampling and fake-capture lifecycle tests; exercise overflow and error teardown without a physical microphone; finish with a signed-app microphone smoke test.

## Definition of done
- [ ] Record a failing behavioral test before implementation (red).
- [ ] Implement the smallest change that passes (green).
- [ ] Refactor with tests green; no live API keys in CI.
- [ ] Run formatting, Clippy and relevant regression/integration tests.
- [ ] Link evidence to each acceptance criterion; document manual checks and unresolved limitations.
