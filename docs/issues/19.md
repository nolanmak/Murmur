## Outcome
Insert finalized text into the original supported X11 input with explicit delivery outcomes.

## Acceptance criteria
- [ ] Revalidate original target before delivery; focus change, vanished target or detected password field blocks automatic insertion.
- [ ] When target identity or sensitive-field safety cannot be established, offer explicit review/copy rather than guessing.
- [ ] Verify Unicode and punctuation in Chromium/Chrome search, Firefox input, a native editor and a terminal; terminal versus GUI paste shortcuts are explicit.
- [ ] Never execute transcript text through a shell, synthesize Enter or silently submit a form; existing multiline policy stays enforced.
- [ ] Preserve clipboard data/types where supported; restore only if ownership/content still belongs to this operation, and document retention limitations.
- [ ] Report paste attempted versus verified insertion honestly; unavailable confirmation must not display an unconditional text-pasted success.

## TDD plan
RED: policy tests for focus races, password/unknown targets, clipboard ownership races, Unicode, cancellation and duplicate delivery. GREEN: X11 adapter using argument-safe APIs. Native tests inspect actual target content, not just successful event dispatch.

## Workflow and definition of done
- [ ] Create an isolated issue branch/worktree from updated main; keep one bounded change per PR.
- [ ] Record the failing behavioral test command/output before implementation, then the passing result; refactor without weakening assertions.
- [ ] Run `cargo fmt --all -- --check`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo test --locked --workspace`, and `python3 scripts/check-repo.py`.
- [ ] Link tests and native evidence to each acceptance criterion; explicitly leave untested criteria open.
- [ ] Use synthetic data only; no credentials, personal paths, hostnames, user audio or transcripts in Git/issues/evidence.
- [ ] Push the issue branch, open a linked PR and remove its temporary worktree after preserving committed work.
